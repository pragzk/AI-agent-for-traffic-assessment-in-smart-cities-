About · PEAS agent architecture

▾

This dashboard drives a rational agent built on the PEAS framework. Ten city zones are evaluated each simulated hour. A rule-based agent fires alerts when the weighted risk score R ≥ 0.60. A Q-learning agent (ε-greedy, tabular) learns to catch the blind spot — zones that are truly dangerous (R* > 0.45) yet fall below the rule threshold.

🌆
Environment
CitySimulator
10 zones with stochastic density & weather each hour. A deterministic true_danger label (R* > 0.45) provides ground truth for the RL reward signal.
👁
Percept
PerceptionModule
Converts raw zone state into a 5-D normalised vector [density, weather_enc, time_flag, hist_risk, is_night]. Small Gaussian noise (σ=0.03) applied during training only.
🧠
Decision
DecisionModule + RLAgent
Rule-based: R = Σ wᵢfᵢ, alert if R > θ = 0.60. RL agent: Q-table over 6-bin discretised percepts (up to 7 776 states); ε decays 1.0 → 0.01 over episodes.
🚨
Action
ActionModule
Issues alerts, logs events with timestamps, and aggregates precision, recall & F1. RL reward shaping: +15 TP, −15 FN, −8 FP, +2 TN — only selective alerting is profitable.
